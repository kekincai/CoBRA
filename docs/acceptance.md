## Stage ごとの到達点

1. Algorithm Verification: 原入力・計算ロジック・独立実装との比較済み。旧 Excel マクロとの完全互換は未検証（ALG-001）。
2. CoBRA MVP: 自社実績 → 校正 → 検証 → 見積り → 履歴を UI と API で実装。
3. Japan Benchmark: 58 集計レコード、4 業種区分、開発種別別の生産性・工程比率・期間。出典がない FP 業種別値は欠損表示。
4. AI Impact: 編集可能な Scenario、工程配分の出所・費用・ROI・保存結果の再表示。
5. Actual AI Learning: 実績記録・予測との差分・手動の Scenario 改訂まで。自動学習・統計的因果検証は今後の対象。
